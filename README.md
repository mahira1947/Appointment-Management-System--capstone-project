# CareFlow — Appointment Management System

React + Tailwind CSS frontend, Spring Boot REST API, MySQL database.

## Roles
- Patient: login, browse doctors, view slots, book and manage own appointments.
- Doctor: login with their own email, view only their appointments, complete/cancel appointments.

## Demo credentials
Patient: `patient@careflow.com` / `patient123`
Doctors: each doctor email / `doctor123`

## Security
JWT bearer authentication, role-based access, BCrypt password upgrade for legacy demo passwords.

## Tech
React 19, Vite, Tailwind CSS 4, Spring Boot 3.5.6, Spring Security, JWT, JPA/Hibernate, MySQL 8.
